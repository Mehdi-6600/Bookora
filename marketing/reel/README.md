## نسخهٔ ۱۵ ثانیه‌ای

نسخهٔ استوری از همان صحنه‌ها بریده شده، ولی **صدا و گویندگی جداگانه** دارد؛
هیچ جمله‌ای از نسخهٔ ۳۰ ثانیه‌ای وسط کلمه قطع نمی‌شود.

| زمان | صحنه | متن روی صفحه |
|---|---|---|
| ۰–۳٫۲ | صندوق پیام پر می‌شود | «پیام مشتری‌ها / تموم نمی‌شه؟» |
| ۳٫۲–۸٫۴ | انتخاب تاریخ، شبکهٔ ساعت‌ها، فرم | «انتخاب ساعت، در چند ثانیه» |
| ۸٫۴–۱۰ | تأیید رزرو | «رزرو ثبت شد / بدون پیام‌های بی‌پایان» |
| ۱۰–۱۵ | لوگو، شعار، آیدی ربات، سه مزیت | «رزرو آنلاین / ساده و هوشمند» |

| ۱۲٫۹–۱۷٫۴ | صاحب سالن + توست «رزرو تأیید شد» | «رزرو ثبت شد / بدون پیام‌های بی‌پایان» |
| ۱۷٫۴–۲۳٫۸ | پنل مدیریت: رزروها، خدمات، ساعت کاری، نمودار | «همه‌چیز، در یک پنل» |

**آیدی ربات:** `@Bookora_App_bot` — همان آیدی‌ای که در `messages/`، `docs/growth/`
و صفحهٔ فرود پروژه استفاده شده است. برای تغییر آن فقط `BOT_HANDLE` در
`build/reelkit.py` را عوض کنید و دوباره رندر بگیرید.

## بازتولید

```bash
python -m venv .venv && . .venv/bin/activate
pip install pillow numpy scipy arabic-reshaper python-bidi soundfile

# ffmpeg: هر بیلد استاتیک 4.x+ کار می‌کند
export FFMPEG=$(node -e "console.log(require('@ffmpeg-installer/ffmpeg').path)")

cd build
python audio.py     # موسیقی + گوینده + میکس ۳۰s و ۱۵s
python render.py    # ۳۰s + ۱۵s + کاور  (≈ ۳ دقیقه روی ۲ هسته)
python subs.py      # زیرنویس‌های فارسی ۳۰s و ۱۵s
python render.py --still 8.5   # یک فریم برای بازبینی
python qa.py ../output/bookora-reel-1080x1920-30s.mp4 /tmp/sheet.png  # کانتکت‌شیت

# یا همه‌چیز با یک دستور:
python build_all.py
```

## قواعدی که در ساخت رعایت شده

- **هیچ فرد واقعی شبیه‌سازی نشده.** عکس زن با یونیفرم ایرلاین که فرستادی استفاده
  نشد؛ سوژهٔ ویدیو یک تصویر کاملاً ساختگی (AI) با شال و کت کرم است، بدون یونیفرم،
  آرم یا نشانهٔ سازمانی.
- **بدون ادعای غیرواقعی.** فقط چیزهایی گفته می‌شود که محصول دارد: صفحهٔ رزرو ۲۴
  ساعته، لینک اختصاصی هر کسب‌وکار، و پنل مدیریت خدمات/ساعت کاری/رزروها. ادعای
  «پاسخ خودکار به دایرکت اینستاگرام» یا آمار ساختگی در ویدیو نیست.
- **داده‌های نمونه.** نام‌ها فرضی‌اند («زهرا و.»، «سارا ک.»، «مینا ب.») و شماره
  `09120000000` است.
- **لوگو دست‌نخورده.** فقط با screen-blend روی پس‌زمینهٔ تیره قرار گرفته و نسبت
  ابعادش حفظ شده است.
- **موسیقی اصلی.** بد موسیقی از صفر با سینتز ساخته شده (`build/audio.py`)، پس
  مسئلهٔ کپی‌رایت ندارد.
- **فونت.** Vazirmatn با مجوز OFL در `assets/fonts/` (متن مجوز هم همان‌جاست).
- **زیرنویس.** متن زیرنویس دقیقاً همان متن روی صفحه است (نه بازنویسی)، پس هیچ‌وقت
  با ویدیو اختلاف پیدا نمی‌کند. زمان‌بندی از `build/subs.py` می‌آید؛ اگر صحنه‌ها
  را جابه‌جا کردی، همان را دوباره اجرا کن.
